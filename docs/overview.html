01 / IN PRACTICE

A clear path through the work.

Follow the input, the decisions and the output. Select a stage to see what happens there.

THE SELECTED STAGE

Arrow keys move between stages.

Load or generate

Start with Synthetic, a labelled MATLAB matrix or equal-length CSV class folders. Use the separate inspector for unlabelled arrays.

Set the sampling rate

Enter the actual rate in Hz and valid band limits. The demo default is not inferred from your file.

Extract and compare

Compute sixteen time/spectral features, inspect plots and standardized PCA, then choose classification and feature-selection settings.

Evaluate and preserve

Split before fitting selection/scaling, inspect held-out results and export a model with its feature order, length and sampling configuration.

05 / THE EVIDENCE

What was checked. What remains open.

Reliable documentation makes the boundary visible rather than promising perfection.

Recorded automated verification
48 scientific, model, storage and export tests passed in existing Conda base; synthetic data only.

  • Independent-signal classification, not blind source separation. Correlated windows or subjects need group-aware evaluation outside this app.
  • Synthetic results do not establish real-data accuracy; repeated holdout exploration can overfit choices.
  • MATLAB v7.3/HDF5 is unsupported. Import only trusted pickle packages with compatible dependencies.
