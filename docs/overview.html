01

Where does the mean-square power go?

A short direct DFT exposes every one-sided bin with the same normalization as the Python FFT route.

Computed here. Nothing is uploaded or written to the application.

Read the mechanism and connect it to the app

RMS=sqrt(mean(x²)). One-sided power is |FFT(x)|²/N², doubling interior bins only; DC and an even-length Nyquist bin occur once. The sum equals RMS². This small direct DFT uses the same definition, not a fast FFT. Default peak2Hz, RMS≈0.7071 and total power0.5. The browser caps input at64 samples. Real SignalLab computes16 features and trains configurable classifiers from larger equal-length datasets.

Source: signallab/core.py: time_features, spectrum, frequency_features

02

The same samples can tell a different frequency story.

Change an ideal tone and sampling rate to see above-Nyquist frequencies fold into the sampled band.

Computed here. Nothing is uploaded or written to the application.

Read the mechanism and connect it to the app

Frequencies separated by multiples of fs yield equivalent sample sequences; fold into [0,fs/2] to find the alias. A70Hz tone at100Hz aliases to30Hz. SignalLab cannot infer the true acquisition rate from a MATLAB array, so enter it before extraction. Saved packages retain sampling rate, bands, signal length and feature order. This is sampling arithmetic, not anti-alias filtering or a source-separation model.

Source: signallab/core.py: FeatureConfig, spectrum, model_package; README.md

BEFORE YOU BEGIN

The questions worth asking.

Clear expectations make a better first session—and a better presentation.

What sampling rate should I enter?

Use the actual rate in Hz. The 1024 Hz default belongs to the demo and is not inferred from an arbitrary MATLAB file.

What if my file has no labels?

Use the MATLAB inspector. The classifier does not invent class labels or silently pad unequal signals.

Can I load any saved model?

Only trusted current-format packages with compatible scikit-learn versions. Pickle files can execute code, so version checks do not make untrusted files safe.

Does it handle repeated windows from one subject?

The workbench is for independent-signal classification. Correlated windows or repeated subjects need a group-aware evaluation design outside the app.

My MATLAB file will not load. What should I check?

Use the inspector to review numeric variables and orientation. MATLAB v7.3/HDF5 files need resaving as v7 for this loader. Classification also requires labels, equal signal lengths and the actual sampling rate.

05 / THE EVIDENCE

Evidence, scope and next steps.

Reliable documentation makes the boundary visible rather than promising perfection.

Recorded automated verification
48 scientific, model, storage and export tests passed in existing Conda base; synthetic data only.

  • Independent-signal classification, not blind source separation. Correlated windows or subjects need group-aware evaluation outside this app.
  • Synthetic results do not establish real-data accuracy; repeated holdout exploration can overfit choices.
  • MATLAB v7.3/HDF5 is unsupported. Import only trusted pickle packages with compatible dependencies.
